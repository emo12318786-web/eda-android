# Eda Phone Agent V0.1

این یک پروژهٔ اندرویدی جدا از EDA/Termux است؛ کد EDA فعلی تغییر نمی‌کند.

## امکانات نسخهٔ اولیه
- ورودی متنی و تشخیص گفتار Android (زبان پیش‌فرض فارسی)
- پاسخ صوتی با موتور TTS گوشی
- زمان و تاریخ
- روشن/خاموش کردن چراغ‌قوه با درخواست اجازهٔ دوربین
- یادداشت محلی و نمایش یادداشت‌ها
- درخواست مجوز فقط هنگام نیاز

## محدودیت‌های فعلی
این نسخه هنوز به مدل زبانی متصل نیست، wake-word دائمی ندارد، در پس‌زمینه کار نمی‌کند و APK امضاشدهٔ انتشار نیست. فرمان‌هایی که ابزار ندارند، صریحاً اعلام می‌شوند و وانمود نمی‌شود که اجرا شده‌اند. پیامک، تماس، حذف فایل، پرداخت و کارهای حساس پیاده‌سازی نشده‌اند.

## ساخت APK
پوشهٔ `phone-agent` را در Android Studio باز کن و Build > Build APK را بزن. خروجی debug APK فقط برای نصب آزمایشی است.
