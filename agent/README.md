# Eda Agent V1 (experimental)

این پوشه یک هستهٔ اولیهٔ Agent برای پروژهٔ Eda است. هدف، اضافه کردن چرخهٔ محدود
**برنامه‌ریزی → اجرای ابزار مجاز → بررسی نتیجه** بدون بازنویسی دستیار فعلی است.

## فایل‌ها
- `agent_core.py`: هستهٔ مستقل؛ بدون وابستگی اجباری به LangChain/LangGraph.
- `test_agent_core.py`: تست‌های پایه.
- حافظه در اولین استفاده به صورت `agent_memory.json` کنار فایل هسته ساخته می‌شود؛
  آن را به GitHub ارسال نکنید.

## ابزارهای اولیه
- زمان و تاریخ دستگاه
- محاسبهٔ ریاضی محدود و امن (بدون `eval`)
- ذخیره و جست‌وجوی یادداشت محلی

## اتصال به Eda فعلی
از پوشهٔ ریشهٔ پروژه می‌توان هسته را به تابع AI موجود وصل کرد:

```python
from agent_core import build_eda_agent

agent = build_eda_agent(ai_sor)  # ai_sor تابع فعلی Eda است
reply = agent.run("حاصل 12 * 8 را حساب کن")
print(reply)
```

این نمونه، اتصال برنامه‌ای را نشان می‌دهد؛ برای فعال کردن آن در مسیر گفت‌وگوی صوتی
باید نقطهٔ فراخوانی در `eda.py` جداگانه و با تست ادغام شود. نسخهٔ اولیه عمداً SMS،
ارسال ایمیل، خرید، حذف فایل یا پرداخت را اجرا نمی‌کند. هر ابزار پرخطر باید تأیید
صریح کاربر و بررسی نتیجه داشته باشد.

## نکات
- مدل ممکن است JSON نامعتبر تولید کند؛ در این حالت به پاسخ متنی برمی‌گردد.
- ابزارها allow-list هستند؛ متن مدل به‌عنوان کد اجرا نمی‌شود.
- این نسخه هنوز یادگیری خودکار، تقویم/آب‌وهوا یا دسترسی مستقیم به Android API ندارد.
- از حافظهٔ محلی داده‌های حساس را ذخیره نکنید.
